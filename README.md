Code to run further experiments based on the Master's Thesis by Tristan Lovšin. 
The difference to the main is that this does not include figures and that the code
includes differing values of alpha, which are used for the input of Automato.
The code is based on the code used in the paper:
'AuToMATo: An Out-Of-The-Box Persistence-Based Clustering Algorithm',
which can be found here: https://arxiv.org/abs/2408.06958.
